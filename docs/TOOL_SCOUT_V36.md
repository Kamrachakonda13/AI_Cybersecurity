# VEYRA v3.6 Tool Scout

## Purpose

Keep the 577-tool ecosystem current without turning the catalog into an ungoverned package list. The scout tracks new security tooling, agent runtime controls, cloud-native policy, supply-chain controls and AI-security projects.

## Review dimensions

1. Security relevance
2. Project maturity and maintenance
3. Provenance and distribution trust
4. License compatibility
5. Worker/runtime compatibility
6. SBOM and artifact verification
7. Evidence quality
8. Tenant isolation and data handling
9. Authorization/approval integration
10. Documentation completeness

## Current scout highlights

The v3.6 radar includes Kyverno, Inspektor Gadget, Prempti, Open Policy Agent, TUF, OpenSSF Scorecard, GUAC, MCP Shield Runtime, Pipelock, Adrian Agent Security and SINT Protocol, plus OWASP ACS and the OWASP GenAI framework crosswalk as control references.

## Definition of done

A newly promoted tool must have an individual `docs/tools/<tool-id>.md` page covering what it does, why it is included, when to use it, UI workflow, terminal starting point, evidence, interpretation, remediation/verification, common mistakes and safety boundary.
