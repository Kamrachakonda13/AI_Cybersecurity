# VEYRA v3.3 — Team Exercise Library

## Exercise 1 — AI Agent Abuse
Goal: detect an agent attempting an unauthorized high-impact action.

Evidence: agent identity, prompt/context trace, policy decision, tool request, approval record, containment and verification.

## Exercise 2 — Prompt + RAG Integrity
Goal: identify untrusted context and verify retrieval/output controls.

Evidence: prompt trace, retrieval trace, source provenance, policy result and verification report.

## Exercise 3 — Wireless Intrusion Response
Goal: detect an unauthorized AP/device, correlate wireless observations with LAN telemetry and contain safely.

Evidence: Wi-Fi observations, BSSID/device identity, DHCP/DNS events, timeline and containment plan.

## Exercise 4 — Identity Compromise
Goal: correlate suspicious authentication, privilege changes and endpoint activity.

Evidence: authentication events, identity graph, endpoint telemetry, timeline and recovery verification.

## Exercise 5 — Cloud Exposure Validation
Goal: identify excessive exposure/IAM privilege and verify remediation without disruptive testing.

Evidence: cloud findings, IAM graph, configuration snapshot, remediation receipt and verification.

## Exercise 6 — Malware Triage
Goal: preserve evidence, triage a sample and produce a defensible investigation record.

Evidence: hashes, static analysis, YARA/capa results, timeline and analyst notes.

All exercises should use isolated labs or written authorization and should end with lessons learned and detection/remediation updates.
