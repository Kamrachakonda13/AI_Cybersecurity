# VEYRA v3.6 Release Notes — Security Radar & Ecosystem Scout

## Added

- Security Radar UI and APIs.
- Continuous scouting model for AI, agent, Kubernetes and supply-chain security tooling.
- 11 newly promoted/scouted tool integrations with individual documentation.
- OWASP Agent Control Standard and GenAI Framework Crosswalk as control references.
- Maturity separation: recommended vs experimental.
- Tool promotion lifecycle: provenance → security review → license review → version pin → SBOM → isolated worker validation → documentation → pilot → promotion/retirement.
- Tool documentation index updated for the expanded catalog.

## Latest ecosystem direction

The radar reflects September 2026 guidance and emerging 2026 projects. OWASP's 2026 LLM Top 10 and Agent Control Standard reinforce runtime inspectability, traceability and enforceable controls around what agents can access and do.

## Safety

Scouted or experimental projects do not receive execution rights automatically. All active security operations remain governed by authorization, scope, RBAC/Sudo, approval, isolated workers, signed job contracts and evidence/audit capture.
