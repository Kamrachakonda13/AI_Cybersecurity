# VEYRA v5.0 Current Research Alignment — September 2026

## NIST

NIST's AI Agent Standards Initiative identifies trusted interoperability, agent authentication/identity infrastructure and secure multi-agent interactions as active areas of work. Its agent identity concept paper specifically calls out identification, authorization, auditing, non-repudiation and prompt-injection mitigation.

## OWASP

The OWASP GenAI Security Project's September 2026 Agent Control Standard emphasizes inspectable, traceable and instrumentable agents with middleware hooks and declarative runtime enforcement. VEYRA's Agent Gateway and Policy-as-Code architecture is designed around the same control-plane principle.

## MCP

OWASP's MCP guidance emphasizes strong authentication/authorization, strict validation, session isolation and hardened deployment. VEYRA therefore treats MCP servers as supply-chain and runtime trust objects, with fingerprinting and drift detection.

## Positioning

VEYRA should remain model-agnostic. Trust attaches to the exact artifact, identity, policy, deployment and observed behavior—not to a model brand or provider.
