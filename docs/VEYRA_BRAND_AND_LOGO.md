# VEYRA Brand & Logo

## Product name
**VEYRA**

## Positioning
**Autonomous Security Intelligence**

## Category
AI-native autonomous cyber defense and continuous exposure validation.

## Brand line
**SEE • REASON • VALIDATE • DEFEND**

## Logo assets
- `frontend/public/assets/veyra-logo.png` — primary brand lockup for hero/marketing surfaces.
- `frontend/public/assets/veyra-mark.png` — compact V/orbit mark for navigation, favicon-style surfaces and compact cards.

## UI guidance
Use the mark in navigation and compact surfaces. Use the full lockup on the overview/home experience. Preserve sufficient dark-space contrast around the logo and do not stretch the aspect ratio.

## Security product identity
VEYRA unifies asset discovery, identity, endpoint, cloud, Kubernetes, AI-agent security, exposure validation, Security Graph intelligence, DFIR and governed response under one security control plane.
