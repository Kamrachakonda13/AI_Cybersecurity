# CVE Triage Policy

When a new CVE is published:

1. Check CISA KEV for known exploitation.
2. Check if the affected software is in our inventory.
3. Assess exploitability given our architecture.
4. Prioritize by CVSS score and exposure.
5. Patch within 30 days for CRITICAL, 90 days for HIGH.

Reference: CISA Known Exploited Vulnerabilities catalog.
