# API Deprecation Policy

## Lifecycle stages

1. **Active**: fully supported, changes announced 30 days in advance
2. **Deprecated**: still functional, no new features, 12-month sunset window
3. **Retired**: removed from the API, requests return 410 Gone

## Notification requirements

- Email notification to registered API consumers
- In-product banner for 90 days
- Blog post and changelog entry
- Direct outreach to top 10 consumers by traffic

## Exception process

Deprecations affecting more than 50% of active consumers require CTO approval.
